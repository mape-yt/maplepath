# 🍁 MaplePath

**Your Journey to Canada, Clearly Tracked.**

MaplePath is a full-stack web application that helps people track their Canadian immigration progress and estimate processing times using community-contributed data.

---

# 🌎 About

Canadian immigration can involve long waiting periods and uncertainty.

MaplePath helps applicants stay organized by allowing them to:

- Track immigration milestones
- Estimate future processing times
- Compare timelines anonymously with other applicants
- Visualize their immigration journey

The first version focuses on the **Manitoba Provincial Nominee Program (MPNP)**, with plans to support Express Entry, other Provincial Nominee Programs, work permits, study permits, and citizenship applications.
